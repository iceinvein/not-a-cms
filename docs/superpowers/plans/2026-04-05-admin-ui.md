# Admin UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `@not-a-cms/admin` package — an Astro app with React islands providing the admin panel: login, dashboard, content list, content editor, and media library.

**Architecture:** Astro 5 app with `@astrojs/react` integration for interactive islands. Uses `@not-a-cms/editor` for the content editing experience and `@not-a-cms/server`'s tRPC client for data fetching. Tailwind CSS for styling.

**Tech Stack:** Astro 5, React 19 (islands), Tailwind CSS 4, tRPC client, @not-a-cms/editor

---

## Task 5: Content List Page

**Files:**
- Create: `packages/admin/src/pages/content/[collection].astro`
- Create: `packages/admin/src/components/ContentList.tsx`

Dynamic route per collection. ContentList React island showing a table with: title, status, author, updated date, actions (edit, delete). Supports basic filtering and pagination.

---

## Task 6: Content Editor Page

**Files:**
- Create: `packages/admin/src/pages/content/[collection]/new.astro`
- Create: `packages/admin/src/pages/content/[collection]/[id].astro`
- Create: `packages/admin/src/components/ContentEditor.tsx`

The main editing experience. ContentEditor is a React island that:
- Renders structured fields sidebar (title, slug, status, relations, etc.) based on collection schema
- Embeds the `<Editor />` from @not-a-cms/editor for the rich text body
- Has save/publish/delete actions
- Uses tRPC to create/update content

# Renderer Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `@not-a-cms/renderer` package — an Astro-based rendering engine for public sites with a theme system, Portable Text block-to-component mapping, multiple rendering modes, and channel rendering (web, RSS, JSON).

**Architecture:** Astro 5 app that fetches content from @not-a-cms/server's API and renders it through theme components. Each Portable Text block type maps to an Astro component. Themes are swappable directory structures with layouts, block renderers, and configuration.

**Tech Stack:** Astro 5, Tailwind CSS, @not-a-cms/core (types)

---

## Task 1: Renderer Package Scaffolding

Setup Astro 5 project in packages/renderer with Tailwind.

---

## Task 2: Content Fetcher

Create runtime/content-fetcher.ts — fetches content from the server's REST API. Supports list and single-document fetching with typed responses. Pure functions, no React.

---

## Task 3: Block Renderer Engine

Create runtime/block-renderer.ts — the core mapping engine. Given a Portable Text block array and a block component registry, returns the appropriate component for each block type. Pure logic, testable. TDD.

---

## Task 4: Default Block Components

Create Astro components for all standard Portable Text block types: paragraph, heading, blockquote, bullet-list, ordered-list, code-block, divider, callout, image. Each renders its block data to semantic HTML.

---

## Task 5: Default Layout + Pages

Create the default layout (header, main, footer), homepage, and catch-all [...slug].astro route that fetches content and renders through the block system.

---

## Task 6: Theme System

Create theme/define-theme.ts and theme/define-component.ts. defineTheme() configures theme metadata and customizable settings. defineComponent() registers components for the future visual site builder.

---

## Task 7: Channel Rendering (RSS + JSON)

Create runtime/channel.ts with renderers for RSS and JSON channels. Create pages/rss.xml.ts endpoint. TDD for the channel conversion logic.

---

## Task 8: Optimized Image Component + Public API

Create the Image.astro component with responsive srcset, lazy loading, and blur placeholder support. Create index.ts with all public exports. Full test run.

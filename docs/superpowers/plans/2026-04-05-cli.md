# CLI Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `@not-a-cms/cli` package — the developer tool for scaffolding, running, building, and deploying not-a-cms projects.

**Architecture:** A Bun-native CLI using `Bun.argv` and a simple command router. Each command is a standalone module. The CLI orchestrates the other packages (core, server, admin, renderer).

**Tech Stack:** Bun (native CLI, no commander/yargs needed)
